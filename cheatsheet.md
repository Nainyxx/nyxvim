# nyxvim — шпаргалка  (Alt+K — закрыть, Пробел — меню всех команд)

## Режимы
  i            печатать (Insert)        Esc   вернуться в Normal
  v / V        выделение символов / строк
  u / Ctrl+r   отменить / вернуть
  Сохранять не нужно — файлы сохраняются сами

## Окна и панели
  Alt+Z        дерево файлов            Alt+X  код
  Alt+C        Claude                   (открывают панель, если она скрыта)
  Alt+T        терминал снизу           Alt+R  запустить код
  Пробел e     показать/спрятать дерево Пробел a c  показать/спрятать Claude
  Ctrl+h/j/k/l перейти в окно ← ↓ ↑ →
  Esc Esc      выйти из режима ввода в терминале/Claude
  Shift+h / l  вкладка влево / вправо   Пробел b d  закрыть вкладку

## Движение (Normal)
  h j k l      ← ↓ ↑ →                  w / b  слово вперёд / назад
  0 / $        начало / конец строки    gg / G  начало / конец файла
  Ctrl+d / u   полэкрана вниз / вверх   %      к парной скобке

## Правка (Normal)
  dd  удалить строку   yy  копировать   p  вставить
  ciw заменить слово   x   удалить символ   .  повторить
  o / O  новая строка снизу / сверху    gcc / Ctrl+/  комментарий
  >> / <<  сдвинуть отступ

## Поиск
  Ctrl+P / Пробел Пробел  найти файл    Пробел f g  текст по проекту
  /текст  поиск в файле   n / N  след. / пред.

## Код
  gd  к определению   gr  где используется   K  документация
  Пробел c a  исправить ошибку / действия    Пробел c r  переименовать
  Пробел d  ошибка целиком   ]d / [d  след. / пред. ошибка
  Пробел x  все ошибки проекта
  Tab / Shift+Tab  выбор в автодополнении    Enter  принять

## Дерево файлов (в панели слева)
  Enter открыть   a создать (папка — с / в конце)   d удалить
  r переименовать   c копировать   m переместить   H скрытые файлы

## Claude
  Пробел a b  дать Claude текущий файл   (в выделении) Пробел a s  отправить
  Пробел a a / a d  принять / отклонить правку   Пробел a r  старые сессии

## Git
  Пробел g g  lazygit   Пробел g b  кто написал строку

## Выход
  :q  закрыть окно    :qa  выйти из nvim
